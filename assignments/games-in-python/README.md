# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game in Python to practice strings, loops, conditionals, random selection, and user input.

## 📝 Tasks

### 🛠️ Select and Display a Word

#### Description
Create the starting state for a Hangman game by choosing a word from a predefined list and showing its letters as blanks.

#### Requirements
Completed program should:

- Choose a word at random from a predefined list.
- Display one blank for each letter in the word (for example, `_ _ _ _`).
- Keep track of the letters the player has guessed.

### 🛠️ Run the Guessing Game

#### Description
Let the player guess letters until they reveal the word or run out of attempts.

#### Requirements
Completed program should:

- Ask the player to guess one letter at a time.
- Reveal each correctly guessed letter in its position in the word.
- Track and display the number of incorrect guesses remaining.
- End when the player guesses the word or runs out of attempts.
- Display a clear win or lose message.
